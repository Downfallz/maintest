# code-reviewer lessons (one line each, with where they came from)

- A summary's "all clear" line must be gated on every input being known, not just on nothing being red: unknown read as green (W6 digest, branch ccr-f0346c35-lt9ro4).
- A try/catch that covers two reads names the wrong one as unread when the second fails: one attempt per field shown (W6 digest, branch ccr-f0346c35-lt9ro4).
- GitHub list endpoints with per_page and no pagination truncate silently; /issues also returns pull requests (W6 digest, branch ccr-f0346c35-lt9ro4).
- A skill meant for a scheduled session with no repository attached cannot be loaded there: the task prompt is the real code, keep it in the repo (W6 digest, branch ccr-f0346c35-lt9ro4).
- An alert or count keyed on a substring of a log line must be grepped against every writer of that text: the startup banner and a sibling worker said it too (W7 ops, branch ccr-1ce109bf-fut95m).
- A Bicep value that moves on every deploy (`utcNow()` into a budget's startDate) must be checked for being updatable in place, not just valid on create (W7 ops, branch ccr-1ce109bf-fut95m).
- A cumulative counter (RestartCount) read with Maximum over a window measures the replica's lifetime, not the window: a "per 15 minutes" alert on it fires as long as the replica lives (W7 ops fixes, branch ccr-1ce109bf-fut95m).
- A word-scanner's exclusion heuristics must be run against the doc's own "Before" examples and against a probe of what they hide: the terminology test exempted lowercase "speed" that the doc lists as legacy, and lowercase sentences as class lists (W8, branch claude/stage-ai-workflow-plan-iczarz).
- An agent prompt that names a heading, label or path must be grepped for it: `sessions`/`decision-times` headings and the `proposal` label did not exist (W8, branch claude/stage-ai-workflow-plan-iczarz).
- A new file under a directory the tests copy to their output (scenarios/, linked by a csproj glob) reaches every test that reads that directory, not just the new ones: grep tests for the old file name and its id to find exact-list assertions (O2 tutorials, ScenariosApiTests.cs:371, branch of d1bf084).
- A JSON shape with an array of records (StepShape[]) lets `[null]` through as a null element: dereferencing it throws NullReferenceException, which the readers' InvalidDataException/JsonException filters do not catch (O2 tutorials, ScenarioFile.Lesson, d1bf084).
- A background answerer that coalesces change signals (busy flag + "again" flag) must not drop "again" on a refused attempt: the refusal is often caused by the very change that set it, so the next question goes unanswered and the script head goes stale (O3a TutorialPlay.AnswerAsync, branch ccr-ae1caee5-8hruvs).
- `TutorialPlay.GaveBack` is raised inside `TutorialPlay._gate` (AssistedSeat.HandBack is called under the lock), so `TableChanges.Bump` and every `Bumped` subscriber (lobby stream, relay) run holding it: check any new subscriber for lock order or I/O (#646, branch ccr-9e6b0958-k6uxyp).
- The branch can move while you review (the author session keeps pushing): re-run `git log origin/main..HEAD` before reporting and re-run the tests on the final HEAD (#612/#613/#615, 21748d4 -> 034f8ea).
- Widening a path-scoped rule's `paths:` to a new folder makes every line of it apply there: read the rule against the folder (pages.md "no build step" now covers showcase/, which has build.mjs) (#613).
- A "replace the destination" guard keyed on two file names (index.html + _headers) still wipes a folder that has those plus anything else: prefer a marker the build itself writes (#613, showcase/build.mjs).
- A masker keyed on the shape of a log line must be grepped against every writer of the free text, not just the writers named in the issue: the void explanation (`voided by X (cat): text`) slipped the `by X[.:]` rule, and free text with a newline becomes a second console row with no prefix to key on (ops names, #624, branch fix/ops-report-names).
- A masking rule keyed on `by <word>` must be probed with framework exception text, not just the audit lines: `Connection reset by peer.` became `by <joueur>.` (ops names, #624, report.mjs unnamed, branch fix/ops-report-names).
- `Console.SetOut` in a test races every other class that does it, since xUnit v3 runs classes in parallel: three Cli.Tests classes now swap the global writer with no shared collection (ops names, #624, PlayersApiTests/OperatorVoidTests/TableTendTests).
- When the browser suite runs in the checkout, gate a copy instead: `git archive HEAD | tar -x` into the scratchpad, copy `table/battle-build` in BEFORE `dotnet build` (the Cli bundle tests read it from the build output), symlink `battle/node_modules` for `npm run build` (O3b, branch ccr-56e5b0ba-aqo26a).
- Text templated from rule values must redo the engine's arithmetic, not the obvious one: floor on a double multiplier (`ResolutionRules.Multiplied`), and every value the sentence silently assumes (a "hit of 7" on the reference creature also reads its Defense). A hand-written "which cards move with which value" map enshrines a missed coupling instead of catching it (#651, branch fix/651-concept-card-numbers).
