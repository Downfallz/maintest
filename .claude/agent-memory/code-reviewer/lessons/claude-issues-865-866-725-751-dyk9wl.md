# code-reviewer lessons (branch claude/issues-865-866-725-751-dyk9wl)
- An index reconciled against a listing by id alone (rows + "closed" ids) heals missing and deleted ids but never a known id whose state changed: a lost note on a closed->open change hides the record for good; ask what re-verifies a *known* id, and whether a note writes the summary it holds or re-reads the record inside the CAS loop (#866, FeedbackIndex.ChangeAsync, 0440b7d).
- A round-2 fix can be build-green and format-red: an expression-bodied generic method with a `where` clause and an object initializer (`=> new(...) { Passes = ... }`) fails `dotnet format --verify-no-changes` (WHITESPACE); run format on every round, not only build (#866, ArtifactStores.cs:168, ec642be).
- A per-item fallback under a rate limit (one GitHub call per filed issue, 60/hour) that restarts in the same order after a cut short starves the tail for good: rotate the start or ask the least recently asked first (#751, admin-feedback.js closedFiled, ec642be).
