# code-reviewer lessons (branch claude/wizardly-newton-3eocoa)

- A provider added beside others leaves the "either provider" / "d'aucun des deux fournisseurs" of a two-provider sentence in the same paragraph it edits: read the whole sentence, both languages (P6, showcase/privacy.mjs:17/52, d9fc6cc).
- A theory of claim checks whose every row breaks the first clause (the issuer) leaves the later ones (tenant) deletable: ask for a row that passes all but the clause it names (P6, MicrosoftSignInTests, d9fc6cc).
- A "this console line means the app is set up wrong" runbook must cover each misconfiguration's own error: Entra's SPA redirect answers 400 invalid_request, which the host counts as a player's refusal and never says (P6, infra/README.md, d9fc6cc).
