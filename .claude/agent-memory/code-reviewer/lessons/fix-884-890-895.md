# code-reviewer lessons (branch fix/884-890-895)

- An offset map built with `[...text]` (code points) but indexed by `match.index`/`slice` (UTF-16 code units) runs short by one per astral character: a refusal near a paragraph's end after many emoji gives `origin[i]` undefined and `whereAt` throws TypeError instead of refusing. Probe offset maps with emoji (#884, scripts/rules/build.mjs traced/rewrite, 6dd162a).
- A null walker over a DTO tree must guard every list it dereferences, not only the ones it hands to its null helper: `node.Children.Select` crashed the new #890 check itself on `"children": null` (STJ without RespectNullableAnnotations writes null into non-nullable lists). Probe `"x": null` as well as `[null]` (#890, GameSchemaBuilder.NullsIn, 6dd162a).
- Third time (O2, R1 feedback, #890): a `[null]` fix covers the DTOs the issue names and leaves siblings: `[null]` in a creature's `startingSpellIds` or a tier's `prerequisites` still throws ArgumentNullException from AliasResolver (6dd162a).
