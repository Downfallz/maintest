- `document.querySelectorAll('dialog:modal').at(-1)` is the last modal in DOM order, not the top of the top layer: a window opened over one later in the markup (atlas over inspect) got a dead Tab, proved by a probe spec on a copy; track opening order instead (UX12 windows.ts topModal, 3a00b72).
- A size floor written as `:is(.a, h4, #some-id)` takes the ID's specificity for every argument, so it also shrinks larger headings it was meant to raise (`#history-detail h4` 14px to 11px): set a floor with `max()`, or keep IDs out of the `:is()` (UX12 battle.css floor, 3a00b72).
- A focus-trap spec that alternates Tab, Tab, Shift+Tab 14 times only reaches 6 controls deep and never Shift+Tabs off the first: it cannot fail on a window with more controls (UX12 battle-windows.spec.js, 3a00b72).
