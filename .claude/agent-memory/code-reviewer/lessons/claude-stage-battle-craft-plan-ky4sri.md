- A "the tremor fills the stop" test that loops over a hand-picked subset ([light, heavy, far]) skips the cases that fail: run the formula on every weight and both deliveries. `round(90/60)=2` made the medium tremor 120 ms against a 90 ms stop, and far light 60 against 30 (BC5, table/battle-motion.js reaction, 0eab6b5).
- A timing test that divides both sides by the rate (`a / speed <= b / speed`) checks nothing about the rate: the rate-dependent risk is in the scene's divisions, so test it there (BC5, battle-motion.test.js, 0eab6b5).
