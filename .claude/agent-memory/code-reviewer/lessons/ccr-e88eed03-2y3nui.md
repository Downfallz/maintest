- A mock that serves a match's whole feed only once `over` (so the replay has history) also hands it to the live seat in one poll, since the cursor sat at 0 all lesson: every `endsMatch` spec now reaches the result through a path no host produces; serve each cast from the poll after its decision, trimmed by `since` (#904, battle-tutorial.spec.js:49, ed6afd0).
- A "Closes #N" on a pull request that settles only the issue's spec gaps drops the issue's other open items (an unanswered question to the owner, a closing paragraph's edge case): ask for "Part of" or a follow-up issue (#904, ed6afd0).
- Mutation for a per-table "opened once" guard in a mock: put the fixed table id back (`practice-lesson`) and the second-pass result assertion goes red at its 15 s wait; proven on small-phone (#904, ed6afd0).
- `SteppedSession.IsOver` is `_outcome.Task.IsCompleted`: true for a faulted ("cannot be played on"), failed-journal or cancelled session too, and it lags the board, since `Take` keeps `_state` (board Ended) before it sets `_outcome`. The seat view's `over` is `IsOver || board.State == Ended` (TableApi.cs:510): a "done when over" read off IsOver alone both widens to crashes and misses the board's window (#912, TutorialPlay.Done, 3a17016).
- Narrowing the host's tutorial `done` (HasEnded: not a faulted or let-go session) leaves the view's `over` (IsOver || board Ended) wider than `done`: battle/src/match.ts drawEnding writes TUTORIAL COMPLETE on `over` alone and Leave then skips. Check the page's reader of every flag a host fix narrows (#912, 800200d).
- A test the PR text lists under "failed before its fix" can be red after it too: run each named test on the HEAD copy, not only main. #912 ScenariosApiTests.A_tutorial_whose_table_could_not_go_on_... answered 200 instead of 404, 3/3 runs alone (e804574).
- A test named for a session that "could not go on" that only calls `Session.Dispose()` takes the let-go path (`TrySetCanceled`), not a faulted one (`TrySetException`, a failed outcome): read which completion of `_outcome` the test really reaches (#912, e804574).
