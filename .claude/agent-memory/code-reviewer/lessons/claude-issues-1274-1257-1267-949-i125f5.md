# code-reviewer lessons (branch claude/issues-1274-1257-1267-949-i125f5)

- A "clear, then write a frame later" announcer is undone by a second synchronous call: `render()` runs twice in one task (order.ts `show()`: skip -> render, then onVisibility -> render), so the region is rewritten before any frame and a screen reader hears nothing; probe the same key twice before the frame (#1267, da91ef1).
- A spec that credits an action to the sequence the page writes on its own live region checks the page's label, not what was said: ask for the text checked against the action too (#1267, da91ef1).
