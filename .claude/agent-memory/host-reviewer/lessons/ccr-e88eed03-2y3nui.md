- `SteppedSession.IsOver` is `_outcome.Task.IsCompleted`: true on a real end (win, loss, concession) but also on let go (cancelled), a bot turn that threw (TrySetException) and a journal that cannot be played on (`Ended`, a failed Result), and those last two raise no `Changed`. Anything that reads IsOver as "the match ended" (tutorial `Done`, `over` in the view) must check `Outcome` succeeded with a success Result (#912).
