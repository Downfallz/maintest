- `SteppedSession.IsOver` is `_outcome.Task.IsCompleted`: true on a real end (win, loss, concession) but also on let go (cancelled), a bot turn that threw (TrySetException) and a journal that cannot be played on (`Ended`, a failed Result), and those last two raise no `Changed`. Anything that reads IsOver as "the match ended" (tutorial `Done`, `over` in the view) must check `Outcome` succeeded with a success Result (#912).
- A read-time fix of a race between two fields of one answer (`over` and `practice.tutorial.done`) is pinned only by a route test that reads once, without `WaitingForAsync` polling: the polling ScenariosApi tests reach `done` through `Look` and stay green if the getter or the `Follow(SteppedSession)` wiring is broken (#912 PR, 800200d).
- `ScenarioPractices.ResumeAsync` lets go of a tutorial only when `Tutorial.Done`; narrowing Done (IsOver -> HasEnded) leaves a practice whose session threw or could not go on resumed on every reload, kept alive by `ByToken` refreshing `Seen`. Whenever Done narrows, check Resume also lets go of `Play.Session.IsOver` (#912).
