- `POST /api/admin/feedback/<id>/scenario.zip` has two under-way guards: FeedbackAdminApi.UnderWayAsync (the report's table) and ScenarioAdminApi.RedactedAsync (the scenario's Session/Source.Run, :294); a fail-closed fix to one leaves the other open, check both (#790 PR).
- `StoredSessions.RecordAsync` returns null for both a missing and an unparseable record (RecordOf swallows JsonException) but throws on a store failure (IO, Azure); a guard that fails closed on null still 500s on a blob outage unless it catches like TableServer.StillOpenAsync (#790 PR).
- The Feedback sheet's `underWay` also offers `diagnose`; treating a missing record as under way offers a Diagnose that answers 404 Diagnosis.NoTable and a note promising a download "once the game is over" that never comes (#790 PR).
