# Replacements

Eleven paintings the owner approved for [the replacement plan](../../../scene-replacement-plan.md), each in place of
a scene that repeats, kept as handed over. A painting reaches its page in the plan's second pull request, when the
page's brief names it and `docs/art/page-pictures.json` declares it ([page-pictures.md](../../../page-pictures.md)).

What a painting shows is named by its content id where it shows a creature or a spell; `studio/ux-pictures.test.js`
checks every id is in `data/`, every file is a row and every size is the file's.
