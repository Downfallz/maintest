# Paintings made for a page

The owner's files for the pictures a brief asked for, unchanged, one file for each picture
([a picture asked of the owner](../../page-pictures.md#a-picture-asked-of-the-owner)). The host does not serve
this folder: `scripts/ux/pictures.mjs` derives what a page is sent from it.

The `round-*.webp` files are not paintings: they are the real battle view, made by `scripts/ux/round.mjs` for the
showcase's round seen played ([a picture of the game itself](../../page-pictures.md#a-picture-of-the-game-itself)).

The `scenes/` folder holds ten paintings made before any brief asked for them. Its [register](scenes/README.md)
gives each one a page, chosen in [the scene paintings' plan](../../scene-paintings-plan.md). A brief draws a scene
once it names it.

The `replacements/` folder holds eleven paintings the owner approved for [the replacement plan](../../scene-replacement-plan.md),
each replacing a scene that repeats; its [register](replacements/README.md) gives their sizes and what they show.
