# SpellCard

A spell's face: warm parchment where it aids reading, inside the slate page.

- `parchment` fill, `parchment-edge` border, `radius-soft`. Title in `spell-title` (display), meta in `parchment-meta`, body at 11px in `parchment-ink` under a `parchment-rule` hairline.
- The parchment and its harm, recovery, protection and control cues are content. They are not a second page theme: never use parchment for a panel or a window.
- The consumer provides the spell's name, its meta line and its effect lines from the authored content.
