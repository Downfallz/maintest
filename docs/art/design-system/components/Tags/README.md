# Tags

Status tags and counters: square tags, round counters.

- `.status-tag`: gold text, `tag-edge` border, `radius-sharp`. In a game card, `.your-turn` sits on `accent-wash` with a gold edge.
- `.casual-tag`: the `tag` style, uppercase, `muted` on a `line` edge; `.ranked` turns text and edge `gold`.
- `.lobby-count` and `.nav-badge` are the only pills (`radius-pill`): they count.
- Every tag is a word. Never colour alone.
