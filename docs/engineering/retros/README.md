# Retros

One file a week, `<yyyy>-W<ww>.md`, written by `/retro` (`.claude/skills/retro/SKILL.md`): the week's numbers
from `scripts/workflow-metrics.py`, the review findings and loose ends seen in at least two pull requests or
issues, and the change to a rule, a skill, an agent or a test made for each. A finding seen once gets one line.
The files are a record: a later retro adds a file, it does not edit an earlier one.
