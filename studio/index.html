Scoring weights

What the heuristic agent values, in points of effective damage (docs/learning/agents.md). They are written next to the run, so a result keeps the weights it was played with.

This is the published page, so there is no engine to play a match here. These run on GitHub Actions instead: each opens the workflow's Run workflow form, and the result lands in the run summary, or on a branch with a link to open it as a pull request.

  • Tune the catalogue One tuning pass over the balance knobs, pushed as a branch with a new benchmark digest and a link to open it as a pull request.
  • Evaluate Two agents over the benchmark seeds; the numbers land in the run summary.
  • Search the agent weights A cross-entropy search of the heuristic agent's eight weights, reported and not applied.
  • Learning loop One turn of the loop: a dataset, two trained policies, and their evaluation as an artifact.
